# DTEK Fact - Четверте джерело даних

## Опис

Додано новий модуль `dtek_fact_loader.py` для обробки графіків відключень з поля `response.fact` у DTEK API. Це джерело має **найвищий пріоритет** серед усіх джерел.

## Пріоритет джерел (оновлений)

1. **DTEK Fact** (з поля `response.fact`) - найактуальніший, з аварійного API
2. **DTEK Schedule** - загальний графік DTEK
3. **YASNO** - офіційний графік
4. **Standard Schedule** - резервний статичний графік

## Структура даних DTEK Fact

### Вхідні дані (з API):
```json
{
  "response": {
    "fact": {
      "data": {
        "1769637600": {
          "GPV8.1": {
            "1": "yes",
            "2": "no",
            "3": "first",
            "4": "second",
            ...
            "24": "no"
          }
        }
      },
      "updateFact": "28.01.2026 21:36"
    }
  }
}
```

### Формат годинних даних:
- **"yes"** = є світло (не відключено)
- **"no"** = немає світла (відключено всю годину)
- **"first"** = відключена перша половина години (00-30)
- **"second"** = відключена друга половина години (30-60)

## Функції модуля

### `parse_dtek_fact_schedule(dtek_alarms_data, group)`
Витягує та конвертує графік з поля 'fact'.

**Логіка:**
1. Перевіряє структуру даних (`response.fact.data`)
2. Конвертує "8.1" → "GPV8.1" для пошуку групи
3. Конвертує timestamp → дату (`1769637600` → `2026-01-29`)
4. Викликає `convert_hourly_to_schedules()` для обробки годин

**Повертає:**
```python
{
    '2026-01-29': {
        'schedules': [
            {'start': '14:00', 'end': '21:00', 'state': 'Definite'}
        ],
        'update_time': '28.01.2026 21:36',
        'date': '2026-01-29T00:00:00'
    }
}
```

### `convert_hourly_to_schedules(hourly_data)`
Конвертує годинний графік у список періодів відключень.

**Алгоритм:**
1. Проходить години 1-24 (час 00:00-24:00)
2. Об'єднує послідовні "no" в один період
3. Додає окремі періоди для "first" та "second"
4. "yes" закриває поточний період відключення

**Приклади конвертації:**

| Годинні дані | Результат |
|---|---|
| `1:"no", 2:"no", 3:"no"` | `00:00-03:00` |
| `5:"first"` | `04:00-04:30` |
| `6:"second"` | `05:30-06:00` |
| `7:"no", 8:"yes", 9:"no"` | `06:00-07:00` + `08:00-09:00` (два періоди) |

### `load_dtek_fact_data(dtek_alarms_url, group)`
Завантажує дані з API та викликає парсер.

## Переваги DTEK Fact

1. **Найактуальніші дані** - оновлюється разом з аваріями
2. **Точна прив'язка до груп** - дані саме для GPV8.1, а не загальні
3. **Детальна інформація** - враховує половини годин (first/second)
4. **Єдине джерело** - аварії + графік в одному API

## Обмеження

1. Якщо групи немає в `fact.data` - використовується наступне джерело за пріоритетом
2. Timestamp повинен бути валідним Unix timestamp
3. Групи мають бути у форматі "GPVx.x" в API

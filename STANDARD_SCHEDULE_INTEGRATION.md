# Інтеграція стандартного розкладу

## 📋 Огляд

Додано підтримку **стандартного розкладу білих зон** як третього (резервного) джерела даних після YASNO та DTEK.

## 🎯 Коли використовується

Стандартний розклад використовується **тільки** коли:
- ❌ YASNO не опублікував офіційний графік
- ❌ DTEK не має даних або вони некоректні
- ✅ Є файл `standart_schedule.json` з розкладом

## 📊 Пріоритет джерел

1. **YASNO** - офіційне джерело (найвищий пріоритет для завтра)
2. **DTEK** - швидше оновлюється (вищий пріоритет для сьогодні)
3. **Стандартний розклад** - резервне джерело (найнижчий пріоритет)

## 🔧 Технічні деталі

### Нові файли
- `standart_schedule_loader.py` - модуль завантаження та конвертації
- `standart_schedule.json` - стандартний розклад по днях тижня
- `process_possible_outages.py` - скрипт обробки `possible_outage` інтервалів

### Змінені файли
- `data_processor.py` - додано параметр `standard_data` в `merge_sources_data()`
- `scan_yasno.py` - додано завантаження стандартного розкладу
- `notifiers.py` - додано попередження про використання стандартного графіку
- `alarms.py` - додано позначку "⚠️ (Стандартний графік)" у попередженнях

## 🔄 Обробка `possible_outage`

Інтервали з статусом `possible_outage` автоматично розбиваються на два по 30 хвилин:

**Логіка:**
- Після `no_power` → перші 30 хв `no_power`, наступні 30 хв `power_on`
- Після `power_on` → перші 30 хв `power_on`, наступні 30 хв `no_power`

**Приклад:**
```
04:00-05:00 possible_outage (після power_on)
  → 04:00-04:30 power_on
  → 04:30-05:00 no_power
```

## 🚀 Використання

### Автоматичне завантаження
```python
from standart_schedule_loader import load_standard_schedule_data

# Завантажити для сьогодні та завтра
data = load_standard_schedule_data()

# Завантажити для конкретних дат
data = load_standard_schedule_data(['2026-01-27', '2026-01-28'])
```

### Формат вихідних даних
```python
{
  '2026-01-27': {
    'date': '2026-01-27T00:00:00',
    'slots': [

      ...
    ]
  }
}
```

## 📝 Підтримка файлу розкладу

Файл `standart_schedule.json` має структуру:
```json
{
  "provider": "DTEK",
  "queue": "6.2",
  "address": "адреса",
  "status": "emergency_outage",
  "week": {
    "monday": {
      "intervals": [
        {"from": "00:00", "to": "01:00", "state": "no_power"},
        {"from": "01:00", "to": "04:00", "state": "power_on"},
        ...
      ]
    },
    ...
  }
}
```

**Важливо:** Файл містить людиночитабельний формат. Конвертація відбувається автоматично при завантаженні.

## ✅ Переваги

1. ✅ **Відмовостійкість** - бот працює навіть якщо API недоступні
2. ✅ **Прозорість** - користувач завжди знає що використовується стандартний графік
3. ✅ **Гнучкість** - легко оновити стандартний розклад при зміні графіків
4. ✅ **Сумісність** - повна інтеграція з існуючою системою повідомлень

# Home Assistant інтеграція

## Опис

Модуль інтеграції з Home Assistant дозволяє перевіряти реальний стан електрики перед відправкою попереджень про відключення/відновлення. Це запобігає відправці непотрібних сповіщень, коли електрика вже відключена або вже відновлена.

## Логіка роботи

### Попередження про відключення
Якщо зараз **світла немає** (за даними HA), то попередження про майбутнє відключення **НЕ відправляється**, бо електрики вже немає.

### Попередження про відновлення
Якщо зараз **світло є** (за даними HA), то попередження про майбутнє відновлення **НЕ відправляється**, бо електрика вже є.

## Налаштування

### 1. Отримання Long-Lived Access Token

1. Відкрийте Home Assistant
2. Натисніть на свій профіль (ліворуч внизу)
3. Прокрутіть до "Long-Lived Access Tokens"
4. Натисніть "Create Token"
5. Дайте йому назву (наприклад, "Yasno Bot Integration")
6. Скопіюйте токен

### 2. Знайдіть Entity ID сенсора

1. Відкрийте Home Assistant
2. Перейдіть до Developer Tools > States
3. Знайдіть свій binary sensor що показує стан електрики
4. Скопіюйте Entity ID (наприклад, `binary_sensor.is_electicity_exists`)

### 3. Налаштування .env файлу

Додайте наступні параметри в `.env`:

```env
# Home Assistant інтеграція
HA_ENABLED=true
HA_URL=http://homeassistant.local:8123
HA_TOKEN=your_long_lived_access_token_here
HA_POWER_SENSOR=binary_sensor.is_electicity_exists
HA_VERIFY_SSL=true
```

#### Параметри:

- `HA_ENABLED` - Увімкнути/вимкнути перевірку стану (true/false)
- `HA_URL` - URL вашого Home Assistant
- `HA_TOKEN` - Long-Lived Access Token
- `HA_POWER_SENSOR` - Entity ID binary sensor для перевірки електрики
- `HA_VERIFY_SSL` - Перевіряти SSL сертифікат (true/false). Якщо використовуєте самопідписний сертифікат - встановіть false

## Приклади логів

### Коли електрика є (on)
```
🏠 Home Assistant: Електрика Є ✅ (sensor: binary_sensor.is_electicity_exists, state: on)
⏭️ Пропускаємо попередження про відновлення - електрика вже є (HA)
```

### Коли електрики немає (off)
```
🏠 Home Assistant: Електрика НЕМАЄ ❌ (sensor: binary_sensor.is_electicity_exists, state: off)
⏭️ Пропускаємо попередження про відключення - електрики вже немає (HA)
```

### Коли HA вимкнено
```
🏠 Home Assistant інтеграція вимкнена (HA_ENABLED=false)
```

### Помилки
```
⚠️ HA_TOKEN не вказано в .env файлі
⚠️ Помилка SSL з'єднання з Home Assistant
⚠️ Час очікування відповіді від Home Assistant вичерпано
```

## Режими роботи

### З HA (HA_ENABLED=true)
- Перевіряється реальний стан електрики
- Непотрібні попередження не відправляються
- Більш точні сповіщення

### Без HA (HA_ENABLED=false або помилка підключення)
- Попередження відправляються завжди за розкладом
- Працює як раніше
- Якщо HA недоступний - не блокує роботу бота

## Безпека

- Токен зберігається тільки в `.env` файлі
- Не логується в логи
- Рекомендується використовувати окремий токен для інтеграції
- Timeout запиту - 10 секунд (не блокує роботу бота)

## Залежності

Модуль використовує:
- `requests` - для HTTP запитів до HA
- `urllib3` - для керування SSL попередженнями

Усі залежності вже додані в `requirements.txt`.

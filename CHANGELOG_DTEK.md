# Changelog - Інтеграція ДТЕК API

## Версія 2.0.0 - 2025-12-13

### 🆕 Нові функції

#### Подвійне джерело даних
- Додано інтеграцію з ДТЕК API (`https://kit.uca.co.ua/dtek_parsed.json`)
- Бот тепер використовує два незалежні джерела: YASNO та ДТЕК
- Автоматичний вибір найсвіжіших даних з доступних джерел
- Відображення джерела оновлення в повідомленнях Telegram

#### Функції обробки даних ДТЕК
- `load_dtek_data()` - завантаження даних з ДТЕК API
- `convert_dtek_to_yasno_format()` - конвертація формату ДТЕК (yes/no/first/second) у формат YASNO (хвилини)
- `merge_sources_data()` - синхронізація та об'єднання даних з обох джерел
- `convert_dtek_to_merged_format()` - fallback для випадку недоступності YASNO

#### Відстеження джерел
- Збереження інформації про джерело оновлення в `states.json`
- Відстеження часу останнього оновлення для кожного джерела
- Логування джерела для кожного оновлення розкладу

### 🔧 Модифікації існуючого коду

#### Оновлені функції
- `load_config()` - додано параметр `dtek_url`
- `is_changed()` - додано параметр `source_info` для відстеження джерела
- `process_day()` - додано відображення джерела оновлення в повідомленнях
- `process_yasno()` - повна переробка для роботи з двома джерелами

#### Покращення логування
- Детальне логування процесу об'єднання даних
- Відображення джерела для кожного оновлення
- Логування порівняння хешів розкладів з різних джерел

### 📝 Оновлення конфігурації

#### .env файл
Додано новий параметр:
```env
DTEK_URL=https://kit.uca.co.ua/dtek_parsed.json
```

#### states.json
Нові поля для відстеження джерел:
- `{group}_{date}_source` - джерело останнього оновлення (yasno/dtek)
- `{group}_{date}_update_time` - час останнього оновлення (тільки для ДТЕК)

### 🔄 Логіка синхронізації

1. **Паралельне завантаження**
   - Дані з YASNO та ДТЕК завантажуються незалежно
   - Якщо одне джерело недоступне, використовується інше

2. **Порівняння даних**
   - Для кожного дня (today/tomorrow) порівнюються хеші розкладів
   - Якщо хеші різні, використовується джерело з іншим розкладом (частіше це ДТЕК, бо оновлюється швидше)

3. **Відправка повідомлень**
   - В Telegram повідомленнях вказується джерело оновлення
   - Зберігається інформація про джерело для відстеження історії

### 🎯 Переваги нової системи

- ✅ **Швидше оновлення** - ДТЕК іноді публікує розклад раніше
- ✅ **Відмовостійкість** - резервне джерело при недоступності основного
- ✅ **Прозорість** - користувач бачить звідки прийшли дані
- ✅ **Надійність** - менша залежність від одного джерела
- ✅ **Гнучкість** - легко додати нові джерела в майбутньому

### 🧪 Тестування

### 📋 Сумісність

- Зберігається повна зворотна сумісність
- Якщо ДТЕК недоступний, бот працює тільки з YASNO
- Старі дані в `states.json` залишаються валідними
- Зовнішній API продовжує отримувати дані в тому ж форматі

### ⚠️ Важливі зміни

- Повідомлення в Telegram тепер містять рядок "📡 Джерело: YASNO" або "📡 Джерело: ДТЕК (оновлено ЧЧ.ММ.РРРР ГГ:ХХ)"
- В `states.json` додаються нові ключі з суфіксами `_source` та `_update_time`

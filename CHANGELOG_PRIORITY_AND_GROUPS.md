# Changelog: Пріоритет джерел та групи в аваріях

## Дата: 2025-01-27

### Зміни

#### 1. Зміна пріоритету джерел даних (data_processor.py)

**Було:**
- YASNO мав пріоритет для завтрашнього дня
- DTEK мав пріоритет тільки для сьогоднішнього дня

**Стало:**
- DTEK має пріоритет для **всіх дат** (сьогодні та завтра)
- YASNO використовується тільки коли дані співпадають з DTEK

**Причина:** DTEK оновлюється швидше та надає точнішу інформацію

**Код:**
```python
# DTEK має пріоритет для всіх дат (швидші та точніші оновлення)
if yasno_hash != dtek_hash:
    logger.info(f"⚡ {target_date}: DTEK має інший розклад - використовуємо його (пріоритет)")
    merged[target_date] = dtek_dates[target_date]
```

#### 2. Відображення груп в аваріях DTEK (dtek_alarms.py)

**Було:**
```
🏠 Будинки: 4, 6, 8
```

**Стало:**
```
🏠 Будинки: 4 (GPV6.2), 6 (GPV6.2), 8 (GPV6.2)
```

**Зміни в коді:**

1. **Структура даних:** Будинки тепер зберігаються як словники:
   ```python
   {'number': '4', 'group': 'GPV6.2'}
   ```

2. **Збір даних:** В `process_dtek_alarms()` додано витягування `sub_type_reason`:
   ```python
   sub_type_reason = house_info.get('sub_type_reason', [])
   group_name = sub_type_reason[0] if sub_type_reason else ''
   
   alarms_groups[group_key]['houses'].append({
       'number': house_number,
       'group': group_name
   })
   ```

3. **Форматування:** Додано функцію `format_houses_list()` для універсального форматування:
   ```python
   def format_houses_list(houses):
       result = []
       for house in houses:
           if isinstance(house, dict):
               if house.get('group'):
                   result.append(f"{house['number']} ({house['group']})")
               else:
                   result.append(house['number'])
           else:
               result.append(house)
       return ', '.join(result)
   ```

4. **Зворотна сумісність:** Код підтримує старий формат (рядки) і новий (словники)
